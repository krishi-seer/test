# MISSION: AUTOMATED SCHEME ENGINE
GOAL: TRANSFORM MANUALLY UPDATED SCHEMES INTO A SELF-SYNCING AI PIPELINE.

## PHASE 1: DATABASE EVOLUTION
- ADD A `SOURCE_URL` AND `LAST_VERIFIED` COLUMN TO THE `SCHEMES` TABLE.
- CREATE A `LOGS` TABLE TO TRACK AUTOMATED UPDATES/REMOVALS.

## PHASE 2: INTEGRATION STEPS
1. CONNECT TO THE E-SANKHYIKI MCP SERVER (URL: https://www.mospi.gov.in).
2. IMPLEMENT A NEXT.JS API ROUTE `/API/SYNC-SCHEMES` THAT:
   - FETCHES DATA FROM BHARAT VISTAAR/AGRISTACK.
   - USES LLM (GEMINI 3.1 PRO) TO NORMALIZE RAW TEXT INTO OUR SCHEMA.
   - UPDATES SUPABASE ONLY IF CHANGES ARE DETECTED.

## PHASE 3: AI-DRIVEN REMOVAL LOGIC
- IF A SCHEME URL RETURNS A 404 OR THE BHARAT VISTAAR API MARKS IT AS 'EXPIRED', 
  THE AGENT MUST ARCHIVE THE ROW INSTEAD OF HARD-DELETING IT.
