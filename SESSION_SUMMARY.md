## 🗄 Database Schema Updates (Supabase)

### 1. Community Page Sync (`farmers` table)
Ensures newly signed-up users are synchronized properly to the community feed.
```sql
DROP TABLE IF EXISTS farmers;
CREATE TABLE farmers (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  age INTEGER,
  location TEXT,
  username TEXT UNIQUE NOT NULL,
  email TEXT NOT NULL,
  avatar_url TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
ALTER TABLE farmers ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow_all_farmers" ON farmers FOR ALL USING (true);
```

### 2. Schemes (`schemes_insert` table)
Ensures agricultural schemes are searchable and integrated.
```sql
CREATE TABLE IF NOT EXISTS schemes_insert (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  url TEXT,
  tags TEXT,
  state TEXT,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
```

### 3. Fertilizer & Irrigation Tracking
Necessary for saving AI-generated soil analysis and water reminders.
```sql
CREATE TABLE IF NOT EXISTS fertilizer_schedules (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  crop_type TEXT,
  crop_stage TEXT,
  field_size NUMERIC,
  soil_analysis JSONB,
  recommendations JSONB,
  total_cost NUMERIC,
  application_dates JSONB,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

CREATE TABLE IF NOT EXISTS irrigation_reminders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  crop_type TEXT,
  field_size NUMERIC,
  soil_moisture NUMERIC,
  recommendation TEXT,
  water_amount TEXT,
  timing TEXT,
  next_irrigation TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
```

## 💻 Key Code Fixes & Optimizations

### 1. AI Chatbot & Voice Assistant Restrictions
- **Path**: `app/api/chat/route.ts` & `app/api/chat-stream/route.ts`
- **Fix**: Updated System Prompts to strictly reject non-agricultural topics (Math, nonsense, general knowledge).
- **Voice Assistant**: Fixed logic bug where overlapping system messages from the client caused API rejection. Added code to filter out frontend-passed `system` roles before hitting the AI provider.

### 2. Internationalization (i18n) Standardization
- **Path**: `public/locales/en/common.json`
- **Fix**: Standardized all translation keys from `camelCase` to `snake_case` (e.g., `signUp` -> `sign_up`).
- **Missing Keys**: Added dozens of missing keys for Fertilizer, Irrigation, and Advisory pages to ensure the UI renders proper text instead of variable names.

### 3. Build & UI Styling Fixes
- **Webpack vs Turbopack**: Disabled `--turbo` in `package.json` to fix "Module not found: Can't resolve 'fs'" error caused by Tailwind v3's Node.js-based config loader.
- **Tailwind Version Conflict**: Corrected `app/globals.css` to use Tailwind v3 directives (`@tailwind base; @tailwind components; @tailwind utilities;`) after finding it was mistakenly using Tailwind v4 syntax.
- **PostCSS Config Fix**: Renamed `postcss.config.mjs` to `postcss.config.js` and switched to `module.exports`, fixing a problem where Next.js was ignoring the styling plugins because of an ESM/CommonJS mismatch.
- **Viewport Scaling**: Added the critical `<meta name="viewport" content="width=device-width, initial-scale=1" />` tag to `app/layout.tsx` to fix the "too zoomed-in" UI issue on high-DPI screens and mobile devices.
